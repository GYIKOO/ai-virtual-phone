# 日历与约定：实施和验收清单

范围：独立分支 codex/calendar-commitments 开发，2026-10-17 用户确认与指令记忆隔离、筑境返回及生图修复一起合并发布。使用设备现实时间及本地时区；不实现虚拟时钟、整周自主重排或额外模型扫描。

- [x] 共用存储：普通周计划与长期约定独立条目、参与角色及用户身份、状态、来源；保护约定投影。
- [x] 共用变更校验：角色仅修改今天/明天普通安排；约定可远期/待定时间；作用域、冲突、幂等、并发与失败原子性。
- [x] 生成/重生成：读取目标周及下一周约定；成功后保存，失败不清空；保留已发生/手动/约定安排，约定时段不被生成覆盖。
- [x] 线上复用内置日历能力；线下单/群聊及剧情单/多人使用同一变更服务，独立剧情禁写主线；只在接受正文后应用附带变更。
- [x] UI：日历约定列表、用户新增/编辑/完成/取消，展示参与者及时间待定；不另造周视图。
- [x] 回归：跨午夜/跨周、现实时间开关无关、远期约定、身份/参与者隔离、重试/中断、重复批次、冲突和生成期间编辑。
- [x] 验证类型/已有测试及本地UI；不启动Ollama、不调用付费模型。

审查一：普通日程和约定不能混为generated；重生成不能先清空再恢复；多角色约定单份关联，生成投影只读。
审查二：权限与当前参与者由宿主决定，模型不能自报任意角色；保存批次使用请求快照+独立ID，失败不影响已保存正文；已有线上工具动作是明确执行，不额外推断普通提议。

## 独立语义复核

复核能力说明、schema及usageGuide、线下/剧情calendar_management协议、周计划触发词与日历marker：仅添加现实日期、可修改范围、约定操作及必要已有安排；未注入文风/字数/视角/亲密关系等创作偏好，没有开发讨论混入正文或记忆。周计划预览与实际生成复用同一触发词。

## 边界

- 能力默认仍关闭，由用户在工具箱开启日历管理。独立IF及未启用的小号链路不写共用日历。
- 已执行的线上工具、已接受正文携带的有效变更成为实际安排；之后删除正文或重试不自动回滚日历。重复新增按相同内容去重，修改/取消用原ID。
- 复用原KV备份键，不引入云端服务、SQL或额外模型轮询。约定按设备当地日期/时段保存，本轮不增加虚拟时间或跨时区自动迁移。
- 支持Web Locks时跨标签页串行保存，不支持时用同页面队列；并发版本校验不代替跨设备同步锁。
